## 판단 보류와 승인 경계

- 점수 가중치·0.50·정책 의미는 변경하지 않았다. 현재 테스트는 기존 동작을 설명하며 점수의 과학적 타당성을 검증하지 않는다.
- main 병합·배포·실제 API·사용자 데이터 전송·인증/스키마 변경은 하지 않았다.
- 첫 수정은 파일 보존을 위해 조립 도구의 동작을 의도적으로 바꾼 버그 수정이다. 외부 동작을 유지하는 순수 리팩터링으로 부르지 않는다.
- 새 경로에 복사하다 실패하면 부분 출력이 남을 수 있다. 이번 수정은 자동 정리·완전한 원자적 빌드·동시 공격자에 대한 파일시스템 격리를 보장하지 않는다.
